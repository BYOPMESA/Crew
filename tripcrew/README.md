# crew.com mockup (29 screens)

Static HTML/CSS mockups of the crew.com mobile screens (390x844), their PNG renders and the PDF export.

- Open `tripcrew/index.html` in a browser for the screen index (each screen is `screens/*.html`).
- `crew-all-screens.pdf` is the 29-page PDF; `crew-invitee-screens.pdf` is the invitee subset.
- `renders/` holds the PNG of every screen; `tools/` holds the generators and the renderer (`render.swift`, macOS).
- Mockup figures (prices, ratings, reviews, names) are sample content only and are not real data.

## Photos
The images in `assets/photos/` are Wikimedia Commons photographs used for the mockup. Per-image author and licence attribution still has to be recorded here before any public release; see the file names for the destination each one shows.
